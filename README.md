# davids-sling

[Play the game](https://crownofthornsworship.github.io/davids-sling/)

Migrated from the existing working game on October 3, 2026. Files in the repository root are the editable game source; assets/ contains existing artwork where applicable. GitHub Pages serves main / root. No build step is needed. The original hosted site was left unchanged.

## Game modes

- **Sling Challenges:** the original 99-level precision-sling campaign with five smooth stones, moving targets, wind, obstacles, and saved progress.
- **David Mode:** a separate 99-level first-person campaign. Read Goliath's spear warnings, dodge left or right, jump low spears, dive-roll beneath high spears, and press one button to throw. David Mode has independent saved progress and supports Easy and Normal difficulty.

Keyboard controls for David Mode: `A/D` or arrow keys to dodge, `W`/Up to jump, `S`/Down to dive-roll, and `Space`/`F` to throw. Large on-screen controls are available on phones and tablets.
